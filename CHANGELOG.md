# Changelog

All notable changes to this project will be documented in this file.

## [0.1.2] - 2026-08-22

### Changed

- adjusted the README logo display width from 96 to 112 pixels for a better
  visual balance on GitHub;
- updated the macOS application and Python package version to 0.1.2.

## [0.1.1] - 2026-08-22

### Changed

- reduced the displayed README logo to a restrained 96-pixel width;
- separated the documentation into complete English and Simplified Chinese
  editions with language-switch links;
- expanded installation, authentication, CLI, QGIS, privacy, and data-governance
  guidance in both languages;
- updated the public GitHub About description in English and Chinese;
- updated the macOS application and Python package version to 0.1.1.

## [0.1.0] - 2026-08-22

### Added

- privacy-conscious macOS launcher source;
- generic Earth Engine project configuration;
- read-only doctor, asset and task CLI;
- public-data geemap notebook;
- install and uninstall scripts;
- macOS CI, smoke tests and privacy scanning;
- bilingual documentation and third-party notices.
